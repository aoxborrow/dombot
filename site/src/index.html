Connect an AI agent

Your portfolio, over MCP.

Dombot runs a local Model Context Protocol server, so an agent can read and manage the same portfolio you see in the app — bound to 127.0.0.1 only, never exposed off your machine.

Connect Claude Code

Run this, then click Approve in dombot.

claude mcp add dombot \
  --transport http \
  http://127.0.0.1:4123/mcp

FAQ

Good to know.

The questions that come up most, in one place.

Is dombot really free?

Yes. The desktop app is free and open source, and stays that way. Optional paid data services may arrive later, but they’re opt-in and separate from the app you download.

Where do my keys and data live?

On your machine. Your portfolio is cached locally and your API keys are encrypted with the OS keystore (Keychain / DPAPI). The free app talks only to your registrars — never to a dombot server.

Do agents need my approval?

Yes. You approve each MCP client inside dombot before it can connect, and you can revoke any client anytime in Settings → MCP Clients.

How do I add a registrar?

Create an API key in that registrar’s account, then paste it into Settings → Registrars and hit Test. Dombot shows exactly where to find each provider’s key. See the supported registrars.
